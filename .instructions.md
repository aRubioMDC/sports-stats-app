## 🛠️ Active Files & Responsibilities

### Backend (Python FastAPI)
- **Main Router**: `backend/app/routers/trends.py` - `/trends/cheatsheet` and `/trends/groups` endpoints
- **Models**: `backend/app/models.py` - PlayerTrendSignal, PlayerWeeklyStat, Game, Team
- **Schemas**: `backend/app/schemas.py` - CheatsheetRowOut, TrendGroupsOut
- **Board Router**: `backend/app/routers/board.py` - Game data and parlay recommendations
- **Database**: PostgreSQL with SQLAlchemy ORM, connection pool optimized

### Frontend (React + TypeScript)
- **Home Page**: `frontend/src/pages/Home.tsx` - Main dashboard (4 widget sections)
- **API Layer**: `frontend/src/api.ts` - React Query hooks and API integration
- **Components**: CheatsheetGroups, AdvancedToolsWidget, ParlaysWidget, GamesGrid, TrendingToday

```powershell

Get-NetTCPConnection -LocalPort $port | Select-Object -ExpandProperty OwningProcess | Get-Unique | Stop-Process -Force
```

### If Frontend Port is In Use:
```powershell
$port = 5174
Get-NetTCPConnection -LocalPort $port | Select-Object -ExpandProperty OwningProcess | Get-Unique | Stop-Process -Force
```

### Testing Endpoints:
- Config: `GET http://localhost:8000/api/nfl/config`
- Board: `GET http://localhost:8000/api/nfl/board?season=2026&week=3`
- Trends: `GET http://localhost:8000/api/nfl/trends/groups?season=2026&week=3`

## 🔄 Workflow

1. **Start Backend**: `cd backend && python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`
2. **Start Frontend**: `cd frontend && npm run dev`
3. **Open Browser**: http://localhost:5174
4. **Verify Endpoints**: Check browser console for API responses
5. **Test Features**: Navigate sections and verify data displays
